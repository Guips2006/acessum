# Sistema de Gestão de Acessos e Usos de Laboratórios

Projeto desenvolvido na disciplina de **Modelagem de Sistemas** da Universidade Presbiteriana Mackenzie.

## Sobre o projeto

O sistema permite que alunos e professores reservem laboratórios e equipamentos, enquanto os ambientes são gerenciados pelos professores responsáveis e pelos administradores.

### Objetivo

Organizar o acesso aos laboratórios, facilitar o controle de reservas e centralizar o gerenciamento de usuários, ambientes e equipamentos.

## Perfis de acesso

O sistema possui três tipos de usuários:

- **Aluno**
- **Professor**
- **Administrador**

## Funcionalidades por perfil

| Perfil | Permissões |
| --- | --- |
| **Aluno** | Reservar laboratórios; devolver reservas; consultar disponibilidade; reportar problemas. |
| **Professor** | Reservar laboratórios; devolver reservas; consultar disponibilidade; reservar equipamentos; reportar problemas. |
| **Administrador** | Adicionar e excluir laboratórios; cadastrar e remover equipamentos; cadastrar e remover usuários. |

## Gestão dos laboratórios

O sistema deve permitir que os usuários consultem a disponibilidade dos laboratórios e realizem reservas conforme suas permissões. Professores responsáveis e administradores também podem acompanhar a utilização dos ambientes e o estado dos equipamentos.
